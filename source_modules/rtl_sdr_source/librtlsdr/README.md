# Bundled librtlsdr

RTL-SDR driver library bundled with the RTL-SDR source module, built when
`OPT_BUILD_BUNDLED_LIBRTLSDR` is on (the default except on Windows and Android).

Based on the RTL-SDR Blog fork, which supports the RTL-SDR Blog V4:
https://github.com/rtlsdrblog/rtl-sdr-blog at commit
`aed0ea19f3a273370a13c9009b96313c75d54c7b` (22 March 2026).

Licensed under the GNU GPL version 2 or later, see `COPYING`.

Only the library sources are included, not the command line tools. Changes
made in this fork are listed in the git history of this directory.
